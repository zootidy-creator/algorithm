## 三、常用输入输出（自己攒的模板）

```c
/* 读一个整数 */
int n; scanf("%d", &n);

/* 读两个整数 */
int a, b; scanf("%d %d", &a, &b);

/* 读一行字符串（含空格用这个，不要用 %s） */
char s[1000]; fgets(s, sizeof(s), stdin);

/* 读 n 个整数（循环） */
for (int i = 0; i < n; i++) scanf("%d", &a[i]);

/* 输出换行 */
printf("%d\n", ans);
```

## 四、提交结果速查

| 结果 | 含义 | 先查什么 |
|---|---|---|
| AC | 通过 | — |
| WA | 答案错误 | 边界值、多组输入、精度、逻辑 |
| CE | 编译错误 | 点进去看报错行；分号/头文件/变量名 |
| RE | 运行错误 | 数组越界、除以 0、指针非法 |
| TLE | 超时 | 算法复杂度太高，或死循环 |
| MLE | 内存超限 | 数组开太大 |
