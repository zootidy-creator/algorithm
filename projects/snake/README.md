> 作者：zootidy-creator ｜ 开始日期：2026-09-27
> 目的：把学过的 C 语法（结构体、数组、函数、指针、循环）串成一个能玩的东西，并补齐多文件编译、随机数、控制台 API、文件读写。

## 怎么编译运行

双击 `build.bat`，或者在 cmd 里：

```cmd
cd /d C:\Users\zzz\source\repos\HelloWorld\projects\snake
build.bat
```

它做的事就是：`gcc -std=c11 -Wall -Wextra main.c snake.c -o snake.exe` 然后运行。

> **为什么要一起写 `main.c snake.c`？** 因为 C 的编译是「每个 .c 单独编译，最后链接成一个 exe」。
> 少写一个 .c，链接阶段就会报 `undefined reference to ...`。

## 文件结构

| 文件 | 作用 |
|---|---|
| `snake.h` | **接口**：常量（棋盘大小、显示字符）、类型（`Point`/`Dir`/`Game`）、函数声明 |
| `snake.c` | **实现**：控制台工具（已给）＋ 游戏逻辑（自己写） |
| `main.c` | **入口**：初始化 → 画一帧 → 退出 |
| `build.bat` | 一键编译并运行 |

## 设计约定

- 棋盘左上角是 `(0, 0)`，`x` 往右增大，`y` 往下增大
- `body[0]` 永远是**蛇头**，`body[len-1]` 是尾巴
- 界面文字用英文（SCORE / GAME OVER），**注释用中文** —— 避免控制台中文编码问题
- 每个功能一个函数，一个函数不超过 40 行
